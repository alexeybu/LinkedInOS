# Strategy

`content-pillars.md` — topics, audience, cadence, goals (SSI, profile views, reachouts). Written
by the not-yet-built `content-strategy` skill.

`calendar.md` — the posting schedule, pillar-rotation order, and the mapping of drafted/backlog
posts onto calendar dates. Written and kept in sync by the `content-calendar` skill.

`trend-notes.md` — periodic web-research findings on LinkedIn format/topic trends and gap
candidates against the pillar list. Written by the `trend-scan` skill; re-run periodically since
trends move fast.
